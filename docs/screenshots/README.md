## How to capture

**Console** (running locally or via the live deployment):
1. Open `http://localhost:5173` or `https://logirush-console.onrender.com`
2. Sign in as `controller` / `control123`
3. Take a screenshot of each page and save it here with the filename above

**Field app:**
1. Run `npx expo start` in `nerFieldApp/`
2. Open on a device or simulator
3. Screenshot each screen listed above
